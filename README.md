# GitHub Workflow Practice

A small sandbox for practicing issues, branches, pull requests, and useful documentation changes.

## Practice workflow

1. Open an issue describing a concrete improvement and its acceptance criteria.
2. Create a branch with a short, descriptive name.
3. Make one focused change and inspect its diff.
4. Open a pull request explaining the problem, change, and validation.
5. Merge when the change is ready, then confirm the result on `main`.

## Scope

Use this repository for learning and small documentation exercises. Keep passwords, tokens, personal data, and production project files out of it.
